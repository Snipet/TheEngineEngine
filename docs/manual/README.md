# TheEngineEngine: the manual

A workshop for engines. Build one (its layout, bore and stroke, cams, intake, turbos or blower, exhaust, fuel and
ECU), put it in a car, start it, rev it, drive it, put it on the dyno, and listen. The sound is not recorded: it is
made, sample by sample, from a physical model of the gas in each cylinder and pipe.

## Start here

- [Getting started](getting-started.md): pick a build, start it, rev it, drive it, read the dyno, change a cam and
  watch the curve move.
- [Controls](controls.md): keyboard, gamepad, and (later) a wheel.
