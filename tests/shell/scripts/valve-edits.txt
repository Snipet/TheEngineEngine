# The application's path from an edit to the engine, on the first build (content/builds/first.json: valve.model Lab,
# the intake phaser's range 60), in the window: each edit held by the document (`param`) and sent to the host (`sent`).
# Edits before the first start, while running, after a stop and a restart, and after a QUALITY change and back. Times
# are seconds from the engine's being ready.
#
# What the engine does with them is checked too: the phasers move and the second cam stage changes from the first
# minute (N1's 83f34ce5: the stage waits for coolant over 10 C with oil pressure; the phasers are commanded from cold).
# -- before the first start: two-stage cams on, the stage change at 300 rad/s (2,865 rpm)
0.10  set valve.stages 1
0.10  set valve.stageSpeed 300
0.50  expect param valve.stages == 1
0.50  expect sent valve.stages == 1
0.50  expect sent valve.stageSpeed == 300
0.60  key return down
0.90  key return up
3.50  expect engine.state == 2
3.50  print
3.50  expect valve.stage == 0
4.00  key w down
6.50  expect rpm > 3500
6.50  expect valve.stage == 1
6.50  expect valve.inPhase > 1
6.50  print
# -- while running: the phaser's range to 0 (parked) and back
6.60  set valve.inPhaseRange 0
7.00  expect param valve.inPhaseRange == 0
7.00  expect sent valve.inPhaseRange == 0
8.00  expect valve.inPhase < 0.5
8.00  print
8.10  set valve.inPhaseRange 60
8.50  expect sent valve.inPhaseRange == 60
9.50  expect valve.inPhase > 1
9.50  print
# -- while running: two-stage cams off and on again, the revs held
9.60  set valve.stages 0
10.00 expect sent valve.stages == 0
10.50 expect valve.stage == 0
10.60 set valve.stages 1
11.00 expect sent valve.stages == 1
11.50 expect valve.stage == 1
11.50 print
11.60 key w up
# -- a stop, edits while stopped, a restart
12.00 key return down
13.40 key return up
15.50 expect engine.state != 2
15.60 set valve.stageSpeed 350
15.60 set valve.inPhaseRange 40
16.00 expect sent valve.stageSpeed == 350
16.00 expect sent valve.inPhaseRange == 40
16.10 key return down
16.40 key return up
19.00 expect engine.state == 2
19.10 key w down
21.50 expect rpm > 3800
21.50 expect valve.stage == 1
21.50 expect valve.inPhase > 1
21.50 print
21.60 key w up
# -- a QUALITY change (the program compiled again and swapped in), then edits
22.00 quality economy
40.00 expect param valve.stages == 1
40.00 print
40.10 set valve.stages 0
40.10 set valve.inPhaseRange 0
40.50 expect sent valve.stages == 0
40.50 expect sent valve.inPhaseRange == 0
40.60 key w down
43.00 expect rpm > 3800
43.00 expect valve.stage == 0
43.00 expect valve.inPhase < 0.5
43.00 print
43.10 key w up
# -- and back to Full, then an edit
43.50 quality full
60.00 print
60.10 set valve.stages 1
60.10 set valve.inPhaseRange 60
60.50 expect sent valve.stages == 1
60.50 expect sent valve.inPhaseRange == 60
60.60 key w down
63.00 expect valve.stage == 1
63.00 expect valve.inPhase > 1
63.00 print
63.10 key w up
64.00 end
